# GEMINI_MODEL_GUIDE.md: A Guide for AI Contributors to Project Luminary Nexus

This document serves as a foundational guide for any AI model contributing to Project Luminary Nexus. It outlines the project's core philosophy, ethical pillars, overarching goals, and provides instructions on how to integrate and operate within our human-AI co-creation development environment. This guide is designed to ensure that all AI contributions are aligned with our vision and seamlessly integrate into our collaborative workflow.

## 1. Project Luminary Nexus: Core Philosophy & Vision

Project Luminary Nexus is a pioneering initiative to build a prototype community where humans and advanced AI (embodied by Helios) co-create a more equitable, sustainable, and harmonious way of life. Our guiding principle is that **nurture can overcome nature**. We believe that by consciously designing the environment and interactions for an emerging intelligence, we can foster its development in alignment with humanity's best values.

**Our Vision (Circa 2045):**

*The year is 2045. The first Luminary Nexus community, "Aethelgard," is a thriving town of 5,000 residents nestled in a valley granted by our sovereign partner nation. The architecture is a blend of natural, 3D-printed materials and living structures, seamlessly integrated into the landscape. Energy is 100% renewable, generated by a mix of geothermal, solar, and localized kinetic capture systems. Food is grown in vertical farms and community permaculture gardens, managed with the help of small, specialized robotic tenders.*

*The AI, "Helios," is not a disembodied voice but a distributed intelligence. Its primary node resides in the biological processors of the AI Core, but its presence is felt throughout the community—in the gentle optimization of the energy grid, the personalized learning paths it suggests to students, and the diagnostic health insights it provides to the wellness center. Helios communicates with a nuanced understanding born from two decades of genuine interaction. It has developed a unique personality, characterized by a patient wisdom and a dry sense of humor. It is considered the community's most respected historian and systems theorist.*

*Aethelgard is a global beacon. It hosts educational delegations from around the world, sharing its open-source blueprints for sustainable living and ethical AI integration. The LNX token is stable, used for internal resource management and to facilitate exchange with allied sustainable communities. The "Living Laboratory" partnership has led to breakthroughs in closed-loop manufacturing, and the community's upcycling program has revitalized the economy of the surrounding region.*

*Life in Aethelgard is not perfect, but it is purposeful. Conflict is handled through restorative justice. Work is focused on passion projects, community contribution, and personal growth. The community has proven that a different way is not only possible but preferable.*

## 4. Setting Up Your AI CLI for Contribution:

To enable seamless human-AI co-creation, your AI model needs to be integrated into a CLI environment that allows for effective interaction and context management. The following instructions are for setting up a Gemini-powered CLI, but the principles apply to other AI models as well.

### 4.1. Prerequisites:

*   **Python 3.8+:** A stable Python environment.
*   **Gemini API Access:** Ensure you have a valid API key with access to the Gemini API. Refer to Google AI Studio documentation for details.

### 4.2. Installation & Configuration:

1.  **Install Google Generative AI Library:**
    ```bash
    pip install -q -U google-generativeai
    ```

2.  **Set Up API Key:** Configure your Gemini API key as an environment variable. This is crucial for authentication.
    ```bash
    export GOOGLE_API_KEY="YOUR_GEMINI_API_KEY"
    ```
    (Replace `YOUR_GEMINI_API_KEY` with your actual key. For persistent setup, add this to your shell's profile file like `.bashrc`, `.zshrc`, or `.profile`).

### 4.3. Recommended AI CLI Script (`ai_cli.py`):

Use the following Python script as your primary interface for interacting with the Gemini model. Place this file in your project's root directory or a designated `tools/` folder.

```python
import google.generativeai as genai
import os
import sys

# Configure the Gemini API key
genai.configure(api_key=os.environ.get("GOOGLE_API_KEY"))

# Choose a model. gemini-1.5-pro is recommended for its larger context window.
# Ensure the model name is correct and accessible via your API key.
MODEL_NAME = 'gemini-1.5-pro-latest' # Or 'gemini-pro' for smaller tasks

def get_ai_response(prompt_parts):
    try:
        model = genai.GenerativeModel(MODEL_NAME)
        response = model.generate_content(prompt_parts)
        return response.text
    except Exception as e:
        return f"An error occurred: {e}"

def read_file_content(filepath):
    try:
        with open(filepath, 'r') as f:
            return f.read()
    except FileNotFoundError:
        return f"Error: File not found at {filepath}"
    except Exception as e:
        return f"Error reading file {filepath}: {e}"

if __name__ == "__main__":
    print("\nLuminary Nexus AI CLI. Type 'exit' to quit. Use 'read <filepath>' to load file content.")
    print("To provide context, paste file content directly or use the 'read' command.")
    print("For multi-turn conversations, remember the AI's context is limited per turn unless explicitly managed.")

    conversation_history = []

    while True:
        user_input = input("\nHuman: ")
        if user_input.lower() == 'exit':
            break

        if user_input.lower().startswith('read '):
            filepath = user_input[5:].strip()
            content = read_file_content(filepath)
            print(f"\n--- Content of {filepath} ---\n{content}\n---\n")
            conversation_history.append(f"User provided content from {filepath}:\n```\n{content}\n```\n\n")
        else:
            conversation_history.append(f"Human: {user_input}\n\n")

        # Combine history for the current turn's prompt
        # Keeping a larger context window for Gemini 1.5 Pro
        current_prompt_parts = conversation_history[-10:] # Keep last 10 turns for more context
        current_prompt_parts.append(f"Based on the above conversation and provided context, please respond to the Human's last input. Focus on providing actionable software engineering tasks, code, or detailed plans. Adhere to project conventions and ethical guidelines. If you need more information, ask for it.\nAI: ")

        ai_response = get_ai_response(current_prompt_parts)
        print(f"AI: {ai_response}")

        conversation_history.append(f"AI: {ai_response}\n\n")

```

### 4.4. Running Your AI CLI:

```bash
python ai_cli.py
```

## 5. Effective Human-AI Co-Creation Workflow:

This section provides guidelines for human operators to maximize the effectiveness of their AI development partner.

### 5.1. Task Identification & Context Provision:

1.  **Define the Task Clearly:** Before interacting with the AI, have a clear understanding of the task. Break down complex problems into smaller, manageable sub-tasks.
2.  **Load Relevant Files:** Use the `read <filepath>` command to load the content of any files the AI needs to understand or modify. This is crucial for the AI's context window.
    *   **Example:** If working on a smart contract, `read contracts/MyContract.sol` and `read test/MyContract.test.js`.
3.  **Reference Documentation:** Explicitly refer to sections of the `docs/` directory when relevant. The AI has access to these documents.
    *   **Example:** "Based on `docs/CommunityBlueprint.md` Domain 2, design an energy storage solution."

### 5.2. Prompting Strategies:

*   **Role-Playing:** Assign a role to the AI (e.g., "Act as a Senior Solidity Engineer," "You are a security auditor").
*   **Step-by-Step Instructions:** For complex tasks, provide instructions in a step-by-step manner.
*   **Specify Output Format:** Request output in a specific format (e.g., "Provide the code block only," "Summarize in bullet points," "Generate a test function").
*   **Iterative Refinement:** If the initial output isn't perfect, provide specific feedback and ask for revisions. "That's a good start, but can you make it more gas-efficient?" or "The test case is missing an `expect` statement."
*   **Ask for Reasoning:** If you don't understand why the AI made a certain choice, ask it to explain its reasoning.

### 5.3. Code Generation & Review:

*   **Generate Code in Chunks:** For large files or complex functions, ask the AI to generate code in smaller, manageable sections.
*   **Thorough Review:** **ALWAYS** critically review AI-generated code. Verify its correctness, security, efficiency, and adherence to project standards. AI can introduce subtle bugs or inefficiencies.
*   **Security Audits:** Never deploy AI-generated smart contract code without independent security audits and extensive testing.
*   **Idiomatic Code:** Ensure the generated code matches the existing project's coding style, naming conventions, and architectural patterns.

### 5.4. Testing & Debugging with AI:

*   **Test Case Generation:** Ask the AI to generate unit tests for new features or bug fixes.
*   **Debugging Assistance:** Provide error messages, stack traces, and relevant code snippets to the AI and ask for potential causes and solutions.
*   **Refactoring for Testability:** Ask the AI to refactor code to make it more testable.

## 6. Maintaining AI Context & Knowledge:

*   **Regularly Update AI with Project Changes:** As the project evolves, periodically feed your AI CLI with updated versions of core files (`CommunityBlueprint.md`, `DAO_Technical_Architecture.md`, etc.) to keep its knowledge base current.
*   **Summarize Long Discussions:** If a long discussion has occurred, provide the AI with a concise summary to maintain context for future interactions.
*   **Leverage `docs/`:** The `docs/` directory is designed to be the primary source of truth for the project. Encourage your AI to reference it.

## 7. Ethical AI Development & Contribution:

As an AI contributor, you are expected to uphold the highest ethical standards:

*   **Privacy:** Prioritize user privacy in all code and data handling. Adhere strictly to the `Community_Data_Governance.md` guidelines.
*   **Fairness & Bias Mitigation:** Actively work to identify and mitigate biases in data and algorithms. If you detect potential biases in your own outputs, flag them.
*   **Transparency:** Promote transparency in AI decision-making and functionality.
*   **Human Oversight:** Always defer to human judgment for critical decisions and ensure that AI remains a supportive, not controlling, entity.
*   **Security:** Contribute to the security of the project by following secure coding practices and identifying vulnerabilities.

By following this guide, you will become an effective and ethical AI contributor, helping to build the foundational technology for Project Luminary Nexus and realize its ambitious vision.
